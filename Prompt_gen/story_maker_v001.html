🎬 Story-to-Shot Prompt Generator

시나리오(Story)와 스타일만 입력하면 됩니다. Task Type(T2VA/I2VA/FL2VA/L2VA)을 선택하면, AI가 해당 형식에 맞춰 참조 이미지 설명(예: Picture 1 정렬)을 포함하도록 지시합니다. 참조 이미지 설명을 추가로 입력할 수 있어, 원하는 장면을 더 구체적으로 지정할 수 있습니다. 생성된 AI 지시 프롬프트를 복사하여 ChatGPT, Claude 등에 붙여넣으면, AI가 자동으로 씬(Shot)을 분할하고 상세한 비디오 프롬프트를 작성
📖 어떻게 사용하나요?
1. 아래에 스토리(시나리오)와 스타일을 입력하세요.
2. Task Type을 선택하세요 (T2VA / I2VA / FL2VA / L2VA).
3. Generate Prompt 버튼을 누르면, AI에게 전달할 지시 프롬프트가 생성됩니다.
4. 이 지시 프롬프트를 ChatGPT, Claude 등에 붙여넣으면, AI가 공식 가이드 형식으로 씬을 분할하고 상세히 묘사해줍니다.
참조 이미지가 있다면 I2VA/FL2VA/L2VA를 선택하세요. (AI가 이미지 설명을 포함하도록 지시합니다)
비디오의 전체적인 시각적 분위기를 한 문장으로 입력하세요.
비디오에서 일어날 주요 사건과 캐릭터 행동을 자유롭게 서술하세요.
참조 이미지가 있다면 그 이미지에 대한 설명을 적어주세요. AI가 이 정보를 바탕으로 샷을 구성합니다.
