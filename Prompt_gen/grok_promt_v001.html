API 키, 결제 없이도 음악 → 시 → 그림 → 영상까지 완성되는 버전

왜 Pro인데도 429가 뜨나요? 결제 없이 사용
Google AI Pro(월 구독)는 gemini.google.com 앱에서 쓰는 거고, Gemini API는 console.cloud.google.com 에서 따로 카드 등록해야 해요.
한국 카드가 등록 안 되면 무료 티어는 오디오 토큰 한도가 0이라서 음악 분석이 무조건 429로 막힙니다.
그래서 이 버전은 API 호출을 아예 안 하고 브라우저 안에서 음악을 분석해서 시와 프롬프트를 만듭니다. 결제가 없어도 바로 시화영상까지 만들 수 있어요.

나중에 카드 등록되면: Cloud Billing에서 프로젝트에 결제 연결 → AI Studio에서 API 키 재발급 하면 Gemini 분석도 쓸 수 있어요.
