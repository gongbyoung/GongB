💡 주요 기능 및 사용 팁 GitHub 이미지 로딩 (CORS 적용) ComfyUI에서 뽑은 이미지를 깃허브나 외부 링크로 가져오실 때 [https://raw.githubusercontent.com/](https://raw.githubusercontent.com/)... 같은 주소를 복사해 넣고 [불러오기]를 누르면 됩니다. 캔버스가 오염(Tainted)되지 않도록 crossOrigin = "anonymous" 속성을 처리해 두어 정상적으로 저장하기가 가능합니다. 로컬 폰트 적용 (.ttf, .otf) 시의 느낌을 살리는 명조체, 캘리그래피 폰트 파일이 컴퓨터에 있다면 [파일 선택] 버튼을 눌러 지정하세요. 자바스크립트의 FontFace API를 사용해 즉각적으로 브라우저 메모리에 로드되어 캔버스에 깨짐 없이 그려집니다. 가로 쓰기 & 세로 쓰기 완벽 지원 정지용 시인 특유의 고전적인 분위기를 연출할 수 있도록 세로 쓰기(우측에서 좌측으로 진행) 알고리즘을 직접 수학적으로 계산하여 캔버스에 구현했습니다. 고해상도 이미지 유지 (캔버스 스케일링) 모니터 화면에는 꽉 차게(비율 유지) 보이지만, 실제 Canvas 객체는 불러온 이미지의 원본 해상도를 그대로 따라갑니다. 따라서 하단의 [이미지 저장하기] 버튼을 누르면 ComfyUI에서 생성한 고해상도 그대로 글자가 선명하게 박힌 이미지를 얻을 수 있습니다. 프론트엔드 작업(Canvas, p5.js 등)에 능숙하시니, 추후 이 코드를 베이스로 불꽃 흩날리는 파티클 효과나 애니메이션 자막 등을 추가하셔도 아주 멋진 결과물이 나올 것입니다! 작동해 보시고 필요한 추가 기능이 있다면 편하게 말씀해 주세요. 이미지는 로컬에서 로딩할거야 Your HTML file is ready HTML 아이콘 poem_editor_local HTML 열기 로컬 이미지 로딩 기능(파일 선택 및 FileReader 처리)과 지정해주신 모든 제어 기능(로컬 폰트, 가로/세로 쓰기, 폰트 크기, 줄/글자 간격, 가로/세로 정렬, 고해상도 저장)을 완벽하게 통합한 완성형 HTML 파일을 생성했습니다. 🛠️ 주요 변경 및 반영사항 로컬 이미지 파일 선택 (): 네트워크 요청(CORS) 없이 컴퓨터 내의 ComfyUI 출력 이미지(.png, .jpg 등)를 선택하면 FileReader를 통해 즉시 고해상도로 캔버스에 로드됩니다. 로컬 폰트 적용 (FontFace API): 로컬에 가지고 계신 한글 명조체나 캘리그래피 폰트(.ttf, .otf)를 선택하면 브라우저 메모리에 수동 로드되어 깨짐 없이 시 구절이 반영됩니다. 세로 쓰기 및 자간/행간 계산: 고전 시화 느낌의 세로 쓰기(오른쪽 줄부터 왼쪽으로 진행)와 가로 쓰기를 모두 지원합니다. 자간(글자 간격)과 행간(줄 간격) 수치를 조절할 때 캔버스에 실시간으로 반영됩니다. 원본 해상도 유지 저장: 화면엔 꽉 차게 보이지만 저장 버튼을 누르면 불러온 로컬 이미지의 원본 픽셀 해상도(4K, 8K 등) 그대로 깨끗하게 합성되어 저장됩니다. 위 파일(poem_editor_local.html)을 다운로드하신 후 브라우저에서 열어서 바로 사용하실 수 있습니다!
