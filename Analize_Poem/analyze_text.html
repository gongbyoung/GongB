LAYER 1

🔍 텍스트 의미 분석기

텍스트를 수치화된 감정·서사 데이터로 추출
분석 항목: 형태소 분석, 개체명 인식, VADER 감정 점수 (긍정/부정/중립), Arousal(흥분도), Dominance(지배력).

서사 구조: 도입(Exposition) → 전개(Rising) → 절정(Climax) → 하강(Falling) → 결말(Resolution)로 문장을 분절.

리듬 추출: 문장별 음절 수의 표준편차를 계산하여 텍스트의 호흡과 속도감을 수치화.

출력 예시 (JSON): { "mood": {"valence": 0.7, "arousal": 0.4}, "segments": [{"act":1, "emotion":"calm"}, ...] }
LAYER 2

🎛️ 시각적 매핑 규칙

분석 데이터를 블렌더 파라미터로 변환하는 변환기
감정가(Valence) → 색상: 긍정적일수록 따뜻한 색상 스펙트럼(오렌지/옐로우), 부정적일수록 쿨톤(블루/바이올렛)으로 World Shader의 Hue를 매핑.

흥분도(Arousal) → 카메라: 수치가 높을수록 카메라 FOV(광각) 증가, 핸드헬드 흔들림(Shake) 강도 증가, 팬 속도 상승.

문장 리듬 → 오브젝트 변형: 짧은 문장이 많을수록 오브젝트의 스케일 키프레임이 빠르게 점프하고, 긴 문장은 부드러운 모프(변형)로 연결.

추상 주제어 (예: '바람', '시간') → 포스 필드(Force Field) 및 시뮬레이션 활성화.
LAYER 3

⚙️ 블렌더 생성 엔진

JSON 명세를 읽어 실제 3D 씬을 빌드하는 실행기
Shader Nodes 자동 구성: 분석된 감정에 따라 Principled BSDF의 Roughness, Metallic, Emission 값을 실시간 연결.

Geometry Nodes 변형: 기본 도형(구, 원통, 평면)에 감정 강도에 따른 Subdivision(세분화) 및 Noise Displacement(왜곡)을 절차적으로 적용.

카메라 시네마토그래피: 서사 단계별로 베지어 곡선 경로(Dolly Track)를 자동 생성하고, 절정 구간에서 급격한 초점 전환(Rack Focus) 키프레임 삽입.

Compositor 후보정: Lens Distortion, Glare, Color Balance 노드를 자동으로 추가하여 영화적 그레이딩 완성.
LAYER 4

🔄 반복 실행 & 렌더링

완전 자동화 파이프라인으로 텍스트만 교체
헤드리스(Headless) 실행: Blender의 --python 인자를 활용하여 GUI 없이 백그라운드에서 씬을 빌드.

입력/출력: `poem.txt` 파일을 감시(Watch)하거나, 웹에서 전달받은 텍스트를 `config.json`으로 저장 → 블렌더가 읽어 씬 구성.

자동 렌더링: 설정된 프레임 범위(예: 300프레임)를 EEVEE 또는 Cycles로 렌더링하여 MP4 파일로 바로 출력.

피드백 루프: 새로운 텍스트가 입력되면 이전 씬을 초기화(Reset)하고 위의 Layer 1~3을 자동 재실행하여 무한히 다양한 뮤직비디오를 생성 가능.

📋 핵심 매핑 규칙 명세서 (Mapping Specification)

텍스트 분석 요소 블렌더 시각화 파라미터 변환 로직 (글로 설명)
감정가 (Valence) World Shader Hue / Bloom Valence -1 ~ 1 범위를 0° ~ 360° Hue에 선형 매핑. (-1=청색, 0=중성 회색, 1=주황색). Bloom 강도는 Valence 절대값에 비례.
흥분도 (Arousal) 카메라 FOV & 회전 속도 Arousal 0~1 → FOV 30° ~ 70° 매핑. Arousal > 0.6 일 때, 카메라에 Random Perlin Noise 기반 흔들림(Shake) 추가.
문장 리듬 (분산) 오브젝트 스케일 점프 음절 분산값이 클수록(불규칙할수록) Geometry Nodes의 Transform 스케일 키프레임 간격이 불규칙하게 변동 (긴장감 조성).
서사 단계 (Act) 카메라 위치/심도 도입: Full Shot(원경), 절정: Extreme Close-up(극근접) + 얕은 피사계심도(낮은 F-stop), 결말: Medium Shot(중경)으로 복귀.
주제어 (키워드) 오브젝트 생성 & 물리효과 '나무/숲' → 다수의 원뿔+구체 군집, '바람/폭풍' → Force Field(터빌런스) 활성화, '시간/노화' → Shader에 Texture Mapping Offset 점진 증가.
※ 위 규칙은 모두 블렌더 Python API를 통해 자동화되며, 사용자는 텍스트만 변경하면 됩니다.

📌 설계도 총론 (Executive Summary)

이 설계는 “텍스트의 숨은 감정과 리듬을 시각적 음악(뮤직비디오)으로 재구성”하는 것을 목표로 합니다.

1️⃣ Layer 1은 텍스트를 수치화합니다. (감정, 서사 단계, 리듬)
2️⃣ Layer 2는 그 수치를 블렌더가 이해하는 색상, 카메라 운동, 변형 강도로 환산합니다.
3️⃣ Layer 3는 환산된 값을 바탕으로 블렌더의 Shader, Geometry Nodes, Compositor를 실시간으로 편집합니다.
4️⃣ Layer 4는 이 모든 과정을 자동화 스크립트로 묶어, 새로운 텍스트가 들어올 때마다 새로운 영상을 렌더링합니다.

결과적으로, 김소월의 시를 넣으면 잔잔한 핑크빛 달리 샷이, 황지우의 시를 넣으면 거친 블루톤의 핸드헬드 샷이 자동 연출됩니다.

⚡ 설계도 기반 아키텍처 · 블렌더 4.0+ / Python 3.11+ 환경 권장 · 웹에서 시각화된 순수 명세서
