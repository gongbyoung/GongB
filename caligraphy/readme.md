# 🖌️ HTML/JS 물리 기반 캘리그라피 엔진 (v50.0 뼈대)

## 🏗️ 아키텍처 구조 (모듈 조합형)
이 엔진은 단일 파일에 모든 코드를 넣지 않고, 각자의 물리적 역할을 담당하는 3개의 JavaScript 클래스를 `calli_engine_v2.html`에서 톱니바퀴처럼 맞물려(Mix & Match) 구동합니다.

1. **`PaperNoiseEngine` (화선지)** : 배경 렌더링 및 픽셀별 요철/섬유질 맵 데이터 제공
2. **`MultiBristleBrush` (가상 붓)** : 입력된 경로를 따라 붓털 입자들을 흩뿌리며 갈필 렌더링
3. **`FluidBleedingSolver` (먹물)** : 붓이 지나간 자리의 픽셀 데이터를 실시간으로 읽어 번짐 연산

---

## ⚙️ 주요 튜닝 파라미터 (변수/함수 사전)

### [A] 다중 붓털 모듈 (`engine_brush.js`)
| 변수/함수 | 타입 | 기본값 | 설명 |
| :--- | :--- | :--- | :--- |
| `config.bristles` | Number | 50 | 붓털 가닥 수. 10으로 낮추면 극단적인 갈필(비백), 150으로 올리면 꽉 찬 묵직한 획이 됨. |
| `config.size` | Number | 20 | 붓 전체의 반경(두께). |
| `speedFactor` | Math | `distance/10` | 획을 긋는 속도 비례 상수. 이 공식을 튜닝하면 마우스(또는 애니메이션) 속도에 따른 붓 벌어짐 감도를 조절 가능. |

### [B] 화선지 모듈 (`engine_paper.js`)
| 변수/함수 | 타입 | 기본값 | 설명 |
| :--- | :--- | :--- | :--- |
| `config.roughness` | Float | 0.5 | 요철 발생 빈도 (0.1 ~ 1.0). 값이 높을수록 화선지 표면이 거칠어져 먹물이 불규칙하게(뾰족하게) 번짐. |
| `generateNoise()` | Method | 난수 | 현재는 `Math.random`을 쓰지만, 향후 p5.js의 `noise()`나 Perlin Noise 알고리즘으로 교체해야 진정한 한지 결이 나옴. |

### [C] 유체 번짐 모듈 (`engine_fluid.js`)
| 변수/함수 | 타입 | 기본값 | 설명 |
| :--- | :--- | :--- | :--- |
| `config.bleedRate` | Float | 0.1 | 1프레임당 먹물이 옆 픽셀로 침투할 확률. 0.8 이상으로 올리면 폭우에 젖은 듯 폭발적으로 번짐. |
| `zone.life` | Number | 60 | 먹물이 젖어있는 프레임 수(건조 시간). 60이면 약 1초간 번지다 멈춤. 300으로 늘리면 끝없이 퍼짐. |
| `nextData[spreadTarget] *= 0.8`| RGB 조작 | 0.8 | 번질 때 주변 픽셀을 얼마나 어둡게(먹색으로) 덮을 것인가. 0.0이면 순흑색, 0.9면 아주 흐린 담묵으로 번짐. |
