🧩 2. 핵심 알고리즘 및 모듈 설명engine_layout.js (다이나믹 구도 & 자동 줄바꿈 엔진)캔버스 비율(1:1, 16:9, 9:16)과 사용자가 지정한 '전체 크기 배율(globalScale)'에 맞춰 가로/세로 '안전 영역(Safe Zone)'을 실시간 계산합니다.텍스트가 길어지거나 글씨를 키우면 단어(어절) 단위로 자동 줄바꿈(Word Wrap)을 수행하며, 절대 화면 밖으로 이탈하지 않도록 비율을 역산하여 방어합니다.중앙 정렬 외에도 계단형, 쐐기형, 물결 춤사위(wave-dance), 갈지자 지그재그(zigzag) 등의 다양한 조형 구도를 지원합니다.engine_brush.js (획 왜곡 및 지렁이 굴곡 엔진)opentype.js를 통해 폰트의 베지어 곡선 좌표를 분해한 뒤, 전단각(기울기), 중심 팽창(Bulge), 곡률(Curvature)을 수학적으로 적용합니다.지렁이 굴곡(Wobble): 삼각함수를 이용해 글자 외곽선 포인트들을 미세하게 떨리게 만들어 인위적인 기계적 느낌을 지우고 손글씨의 유기적인 맛을 극대화합니다.장획(Attractor) 어트랙터: 문장 맨 마지막 글자의 끝획을 수직 하강 혹은 사선 방향으로 길게 끌어내려 캘리그라피 특유의 멋을 살립니다.engine_fluid.js (먹물 번짐 및 화선지 질감 엔진)셀룰러 오토마타 (Cellular Automata): 붓이 지나간 픽셀의 가장자리를 탐색하여, 화선지 섬유질 위로 먹물이 뭉게뭉게 스며드는(Bleeding) 사실적인 수묵화 번짐 효과를 연출합니다.순백 화선지, 미색 고서지, 먹지, 투명(Alpha) 배경 질감을 제공하며, 서예 전통 주문(붉은색)/흑묵 인장(낙관)을 자동 생성합니다.main.js (스튜디오 제어 및 디바운싱 최적화)SRT 자막 파일을 파싱하여 타임라인 세션을 자동 구축하고 리스트 클릭 시 해당 구간으로 즉시 점프합니다.로컬 폰트 업로드: 사용자가 소장한 .ttf, .otf 파일을 FileReader와 opentype.js로 즉시 파싱하여 새로운 뼈대 폰트로 곧바로 활용할 수 있습니다.디바운싱 프리뷰 & 홀드 타임: 슬라이더 조작 시 0.15초의 딜레이를 주어 렉 없이 쾌적하게 수치를 조절할 수 있게 최적화했으며, '완성 후 정지 시간(Hold Time)'을 설정하여 영상 소스로 바로 쓸 수 있도록 여유 시간을 확보합니다.⚙️ 3. 주요 파라미터 및 튜닝 가이드파라미터 명칭UI 컨트롤러 ID조절 범위설명전체 크기 배율#param-global-scale0.3 ~ 3.0캘리그라피 전체 크기를 키우며, 크기에 비례해 자동 줄바꿈이 작동함가로/세로 위치#param-offset-x / y-1000 ~ 1000화면 내에서 텍스트 블록의 상대적 위치를 자유롭게 이동지렁이 굴곡#param-wobble0.0 ~ 2.0글자 외곽선에 수전증/손글씨 떨림 효과를 주어 유기적인 형태감 부여수분(먹물 번짐)#param-bleed0.0 ~ 1.0픽셀 확산 알고리즘을 통해 획 테두리가 화선지에 스며드는 정도 조절완성 후 정지시간#param-hold-time0.0 ~ 5.0초글씨가 다 써진 후 다음 자막으로 넘어가기 전 화면에 고정되어 있는 시간장획 강도#param-attractor0.0 ~ 3.0마지막 글자의 꼬리(끝획)를 길게 늘려 빼는 강도🚀 4. 향후 확장 가능성 (To-Do)Web Worker 분리: 유체 번짐(applyBleeding) 연산을 백그라운드 스레드로 이전하여 대해상도(4K) 렌더링 시 프레임 드랍 원천 차단커스텀 템플릿 저장 기능 고도화: LocalStorage에 저장된 사용자 커스텀 템플릿을 JSON 파일로 내보내고 불러오는 프리셋 매니저 확장
